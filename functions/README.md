# Cloud Function ارسال اعلان (sendNotificationToAll)

این پوشه یک Cloud Function به اسم `sendNotificationToAll` دارد که پنل ادمین
(دکمه‌ی «ارسال برای همه») آن را صدا می‌زند. چون فرستادن پوش به همه‌ی توکن‌های
ذخیره‌شده در دیتابیس نیاز به دسترسی Admin SDK دارد، این کار را نمی‌شود مستقیم
از کد کلاینت (مرورگر) انجام داد — به همین دلیل یک Cloud Function جداگانه لازم
است. **بدون دیپلوی این تابع، دکمه‌ی «ارسال برای همه» کار نمی‌کند.**

## پیش‌نیازها
1. پروژه‌ی فایربیست باید روی پلن **Blaze** (Pay as you go) باشد — Cloud
   Functions حتی برای استفاده‌ی رایگان به این پلن نیاز دارد. از Firebase
   Console → Project settings → Usage and billing فعالش کن.
2. [Firebase CLI](https://firebase.google.com/docs/cli) نصب باشد:
   ```
   npm install -g firebase-tools
   ```
3. با همان حساب گوگلی که به این پروژه (`new-movie-396bc`) دسترسی دارد لاگین کن:
   ```
   firebase login
   ```

## دیپلوی
از پوشه‌ی ریشه‌ی پروژه (همان‌جایی که فایل `firebase.json` هست):
```
cd functions
npm install
cd ..
firebase deploy --only functions
```
بعد از اتمام، در خروجی ترمینال یک آدرس/تاییدیه برای تابع `sendNotificationToAll`
می‌بینی. از این به بعد دکمه‌ی «ارسال برای همه» در پنل ادمین همین تابع را صدا می‌زند.

## چیزی که این تابع خودش تضمین می‌کند
- فقط کاربری که سندش در مجموعه‌ی `admins/{uid}` وجود دارد می‌تواند این تابع را
  صدا بزند (دقیقاً همان قانونی که ورود به پنل ادمین را کنترل می‌کند) — از سمت
  سرور چک می‌شود، نه فقط در ظاهر پنل.
- توکن‌هایی که فایربیس آن‌ها را «نامعتبر/منقضی» اعلام کند (مثلاً کاربر سایت را
  از مرورگرش پاک کرده) به‌صورت خودکار از Firestore حذف می‌شوند.
- ارسال به‌صورت دسته‌ای (حداکثر ۵۰۰ توکن در هر درخواست به FCM) انجام می‌شود، پس
  محدودیتی روی تعداد کاربران ندارد.

## اگر دیپلوی نکرده باشی
پنل ادمین یک پیام خطای واضح نشان می‌دهد ("تابع ارسال اعلان روی سرور پیدا نشد")
به‌جای شکست بی‌صدا یا رفتار Mock — یعنی تا وقتی این تابع را دیپلوی نکنی، بخش
ارسال اعلان به‌طور صادقانه غیرفعال می‌ماند.
